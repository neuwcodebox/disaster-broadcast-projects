# 하늘에서 쏟아지는 물

국가 규모의 파괴로 확대되는 가상 재난방송 작품의 조사 작업공간이다. 작품 제목은 미정이며 `skyfall`은 임시 폴더 식별자다. 작품 속 사건과 향후 작성할 문자·뉴스·기관 조치는 허구다.

한 마을에 내리던 국지성 호우가 수도꼭지에서 나오는 물처럼 연속적인 낙수로 바뀐다. 공급되는 물의 양과 낙수 범위가 계속 증가하고, 지표에 도달한 물은 지형을 따라 파괴적으로 퍼진다. 재난의 발생은 비현실적이지만 물의 작용, 주민 행동, 기관의 판단과 대응은 현실의 조건에 따른다. 국가가 유지되기 어려워지는 규모까지 진행되는 사건이다.

## 조사 기록

- [treatment.md](treatment.md): 8분 30초·7개 장면의 첫 구성안. 작중 약 30시간의 사건 전개, 대피 주민의 채팅, 기관 발표와 수신 경로, 결말 제안을 담는다.
- [research.md](research.md): 확정된 전제, 물리적 결과와 계산, 관측 장애, 지자체·현장기관·중앙의 대응 예측, 방송에 공개되는 정보, 출처와 추가 조사 항목.
- 조사 기준일: 2026-11-15. 작품의 배경 날짜는 아직 정하지 않았다. 현재 제도는 창작의 출발점이며, 배경 날짜가 정해지면 해당 시기의 법령·기관명·지역 매뉴얼을 대조한다.

## 확정된 창작 방향

- 초반에는 종종 있는 국지성 호우처럼 시작한다.
- 이후에는 빗방울이 매우 세게 내리는 정도를 넘어 연속적인 물이 쏟아진다.
- 물의 공급량과 낙수 범위가 계속 커진다.
- 관측장비가 기능을 잃고, 물과 토사가 지형을 따라 주변을 파괴한다.
- 국가 규모로 멸망에 가까워지는 상황을 다룬다.
- 이전 작품의 나폴리탄식 규칙이나 매체 오염을 이어받는 구성이 아니다. 재난 자체의 비현실성과 현실적인 대응을 중심으로 한다.

## 다음 집필에서 정할 것

첫 구성안에서는 8분 30초 분량과 첫날 오후부터 다음 날 저녁까지의 전개, 수송이 끊긴 집결지와 남아 있는 수용지역의 안내를 함께 보여주는 결말을 제안했다. 사용자 확정 전의 초안이며, `research.md`의 예시 수치도 검토용이다. 작품 제목·배경 날짜·발생 지역, 낙수 높이와 속도, 면적·유량 증가 양상은 후속 집필에서 정한다.

실제 지역을 정한 뒤 지형·수계·도로·관측소·임시주거시설·병원과 해당 지자체의 공개 매뉴얼을 대조하고, 사건 발생·기관 확인·결정·공개 발표·현황판 수신의 시간표를 작성한다.

## 제작 상태

`dbs init`으로 작업공간을 초기화했다. [scenario.yaml](scenario.yaml)에는 허구 고지와 함께 CLI의 기본 예제가 들어 있다. 예제의 날짜·기관·문안은 집필 때 작품 설정에 맞춰 바꾼다.

작품 폴더에서 다음 명령으로 시나리오를 검증하고 미리 보거나 출력한다.

```sh
npx dbs validate scenario.yaml
npx dbs preview scenario.yaml
npx dbs render scenario.yaml --out output/film.mp4
```

원본 음원과 음원 생성 코드는 `src/audio/`, 원본 지도와 그리드 생성 코드는 `src/maps/`에 둔다. 생성한 음원과 그리드는 각각 `output/audio/`, `output/maps/`에 저장한다. 영상과 출처 파일도 `output/`에 둔다. 시나리오 필드는 설치된 CLI의 `npx dbs schema`로 확인한다.
