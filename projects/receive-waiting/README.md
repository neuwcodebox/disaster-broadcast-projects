# 보이스 피싱

5분 10초의 한국형 재난방송 호러 단편. 공개 재난문자와 뉴스를 모아 보여주는 현황판 생방송에서 전화 통화 장애가 경기·강원으로 번지고, 뉴스와 문자, 시청자 채팅에 같은 질문이 나타난다. 모든 사건·문자·뉴스·채팅·기관의 조치는 창작이다. 시작 5초에 허구 고지를 표시한다.

## 파일과 재출력

- `scenario.yaml`: 작품과 연출의 작성 원본.
- `audio/`, `audio-code/`: 작품 고유 배경·전화·반송음. CC0-1.0.
- `build-audio.mjs`: 필요할 때 작품 고유 음원 세 개를 다시 생성한다. 문자 수신음과 상태 알림음은 엔진이 제공한다.
- `description.txt`: 영상 게시 설명에 포함할 허구 고지와 자료 출처.
- `commentary.md`: 결말을 포함한 관람 후 작품 해설.
- `output/`: 영상, 썸네일, 렌더링 메타데이터와 출처 파일을 보관하는 로컬 폴더.

Node.js 22 이상에서 저장소 루트의 의존성을 설치한 뒤, 작품 폴더에서 DBS 0.3.0 이상의 CLI를 실행한다.

```sh
npx dbs validate scenario.yaml
npx dbs preview scenario.yaml
npx dbs render scenario.yaml --out output/voice-phishing.mp4
```

`dbs audio`는 필요한 작품 고유 소리를 생성할 때 사용한다. 기존 음원으로 바로 렌더링할 수 있다. 영상은 1920×1080, 60fps다.

## 지도와 시간

허구 고지가 걷히면 생활 뉴스와 전날 밤의 도로 공사·안개 안내, 이미 오간 채팅이 보인다. 00:10에 철원군 통화 장애 문자가 도착하고, 00:13에 하단 뉴스가 통화 장애 보도로 바뀐다.

청회색 채우기는 통신재난 관련 문자 발송 이력이다. 새 문자 수신 때 대상 지역의 채우기가 부드럽게 밝아졌다 원래 상태로 돌아간다. 기본 지도와 테두리는 유지한다. 도청 발신이라도 본문에 특정 시군을 명시한 문자는 그 시군만 대상이다. ‘강원 전역’ 안내는 내장 SGIS 경계의 18개 시군 전체를 대상으로 한다.

노랑·주황·붉은 윤곽선은 과기정통부가 작중 발령한 방송통신재난 위기경보 ‘주의’·‘경계’·‘심각’의 범위다. 문자 발송 지역과 위기경보 지역은 별개의 사실이다. 마지막 출처 불명의 문자는 대상 지역을 알 수 없어 지역 강조를 끈다.

01:40과 03:25에 이전 화면을 유지한 채 시계가 1.5초 동안 전환된다. 컷 시작 1.8초 뒤 새 뉴스와 지도 윤곽선이 표시되고, 2.3초 뒤 발령 문자가 도착한다. 세 번째 컷의 상태 표시에는 중대본 가동을 알린다. 일반 구간은 실시간이다.

## 사건과 발표

화천의 한 주민이 통신사 점검 전화인 줄 알고 집 주소를 알려줬다고 신고한다. 신고인과 연락이 끊기자 경찰은 자택 주변을 수색한다. 연천과 포천에서도 전화를 받고 나간 가족과 연락이 끊겼다는 신고가 이어져, 경기도는 전화에 따라 외출하지 말라고 안내한다. 이후 화천 수색대 무전에 위치를 묻는 음성이 들어오고, 녹음을 들은 가족은 화천 신고인의 목소리라고 진술한다. 일부 수색이 중단되는 동안 통신사는 신고된 회선을 확인하고 장애 구간을 분리한다. 이후에도 다른 지역에서 이상 통화 신고가 접수된다.

뉴스는 신고·가족 진술·기관이 확인한 조치를 전한다. 문자는 해당 지역 주민에게 신원 확인, 문자 신고, 실내 대기를 안내한다. 과기정통부가 위기경보를 발령하고, 지자체와 행정안전부가 주민 행동을 안내한다. 범정부 대응이 시작된 뒤에는 중앙재난안전대책본부가 대피 안내를 맡는다. 기관별 역할과 용어는 공개 자료를 참고했고, 2031년의 발령 범위와 문안은 작품 설정이다. [재난문자방송 기준 및 운영규정](https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000274384) · [과기정통부 방송통신재난 위기경보 발표 사례](https://eiec.kdi.re.kr/policy/materialView.do?num=264761)

채팅에서 원주의 시청자는 아직 겪지 않은 일을 지켜보고, 포천의 시청자는 동생에게 직접 문자해 전화 내용을 확인한다. 화천의 시청자는 어머니가 자기 옆에 있는데도 어머니 번호로 전화가 왔다고 쓴다. 이 대화는 각 시청자가 보고 들은 범위에 머문다. 현황판 운영자는 개인정보를 채팅에 올리지 말아 달라고 알리고, 후반에는 뉴스 수신이 멈춘 상태를 채팅으로 공지한다.

## 결말과 음향

04:40에 중대본이 이후 대피 안내를 재난문자로만 전하겠다고 알린다. 04:43에 뉴스 띠와 음향이 사라진다. 04:50에 생방송에서 전화음이 들리며 뉴스 띠에 주소 질문이 뜬다. 질문은 재난문자와 화천 시청자의 채팅에 차례로 나타난다. 끝부분에는 같은 문자가 0.25초 간격으로 쌓이며, 05:00과 05:03에 수신음이 울린다. 마지막 문자 직후 화면과 소리가 즉시 끊기고 검은 화면으로 끝난다.

배경음은 59.7/119.4Hz 사인파와 저역 잡음, 전화음은 437+483Hz, 반송음은 177/181Hz다. Tone.js와 Chromium Offline Web Audio로 직접 합성했다. 문자 수신음과 상태 알림음도 엔진의 창작 합성음이며 실제 경보음·음성·TTS·외부 음악은 없다. 유튜브에 게시할 때는 `description.txt`를 사용한다. 출력과 함께 생성되는 `.credits.txt`에는 전체 자료 출처가 기록된다.


시나리오는 `audio/`의 무손실 FLAC 음원을 사용한다. 음원을 재생성한 경우 YAML의 해당 경로를 생성된 WAV 파일로 바꾼다.
