# 수신 대기

5분 10초의 한국형 재난방송 호러 단편. 전화 통화 장애로 시작한 신고가 경기·강원으로 번지고 안전을 알리던 매체까지 같은 질문을 보내기 시작한다. 모든 사건·문자·뉴스·기관의 조치는 창작이다. 시작 5초에 허구 고지를 표시한다.

## 파일과 재출력

- `scenario.yaml`: 작품과 연출의 작성 원본.
- `audio/`, `audio-code/`: 작품 고유 배경·전화·반송음. CC0-1.0.
- `build-audio.mjs`: 필요할 때 작품 고유 음원 세 개를 다시 생성한다. 공통 문자 수신음은 엔진이 제공한다.
- `description.txt`: 영상 게시 설명에 포함할 허구 고지와 자료 출처.

Node.js 22 이상에서 제공된 최신 CLI `.tgz`를 이 폴더에 설치한다.

```sh
npm install /path/disaster-broadcast-studio-0.1.0.tgz
npx dbs validate scenario.yaml
npx dbs render scenario.yaml --out receive-waiting.mp4
```

`dbs audio`는 필요한 작품 고유 소리를 생성할 때 사용한다. 기존 음원으로 바로 렌더링할 수 있다. 영상은 1920×1080, 60fps다.

## 지도와 시간

청회색 채우기는 재난문자 발송 이력이다. 새 문자 수신 때 대상 지역의 채우기가 부드럽게 밝아졌다 원래 상태로 돌아간다. 기본 지도와 테두리는 유지한다. 도청 발신이라도 본문에 특정 시군을 명시한 문자는 그 시군만 대상이다. ‘강원 전역’ 안내는 내장 SGIS 경계의 18개 시군 전체를 대상으로 한다.

노랑·주황·붉은 윤곽선은 작중 통신재난 위기경보 ‘주의’·‘경계’·‘심각’의 발령 범위다. 문자 발송 지역과 위기경보 지역은 별개의 사실이다. 지도와 문자의 일치 여부는 전수 대조했다. 마지막 출처 불명의 문자는 대상 지역을 알 수 없어 지역 강조를 끈다.

01:40과 03:25 컷 경계에서 기존 위치의 시계를 밝게 강조하고 숫자가 빠르게 이동한 뒤 도착 시각을 잠깐 유지한다. 전환은 4.2초이며 이전 화면을 유지한다. 새 뉴스·상태는 4.5초 뒤, 발령 문자는 4.9초 뒤 도착한다. 일반 구간은 실시간이다.

## 결말과 음향

전체화면 행동요령은 사용하지 않는다. 주민에게 필요한 지시는 문자로 전달한다. 뉴스의 주소 질문이 문자와 상태 표시로 번진다. 끝부분에는 같은 문자가 0.25초 간격으로 빠르게 도착해 목록을 채우며, 매 네 번째 문자에만 수신음을 울린다. 마지막 문자 직후 화면과 소리가 즉시 끊기고 검은 화면으로 끝난다.

배경음은 59.7/119.4Hz 사인파와 저역 잡음, 전화 느낌은 437+483Hz, 반송음은 177/181Hz이다. Tone.js와 Chromium Offline Web Audio로 직접 합성했다. 공통 수신음도 엔진의 창작 합성음이며 실제 경보음·음성·TTS·외부 음악은 없다. 출력과 함께 생성되는 `.credits.txt`를 게시 설명에 포함한다.


첨부용 사본은 작품 음원을 무손실 FLAC으로 변환하고 YAML 경로를 맞췄습니다. 음원을 재생성하면 각 자산 경로를 audio/해당이름.wav로 바꾸면 됩니다.
